# JavaScript Interactive Form Lab

Website based on the provided JS Assignments 4 PDF.

## Files
- `index.html` — forms and page structure
- `style.css` — responsive design
- `script.js` — DOM input, change, and submit event logic

## Included tasks
1. Live username character counter and password length check.
2. Subscription plan dropdown and terms checkbox validation.
3. Registration form validation and dynamically generated profile cards.

## Run locally
Keep the three website files in the same folder and open `index.html` in a browser.

## Publish with GitHub Pages
Extract the ZIP, upload `index.html`, `style.css`, and `script.js` to the root of your GitHub repository, then go to **Settings → Pages**. Select **Deploy from a branch**, choose `main` and `/(root)`, and save.
